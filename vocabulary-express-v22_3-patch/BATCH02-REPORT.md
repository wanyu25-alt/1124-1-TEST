## 1. 修改內容
1. **教材來源管理**（教師專區 → 📖 詞彙庫最上方「📚 教材來源管理」）
   - 正式內建教材：一律使用，不能停用。
   - 舊版內建教材（18 張）、教師自訂教材：**預設不使用**，各有一個啟用／停用按鈕，並列出詞彙數與有圖片的數量。
   - 停用 = 不進入學生練習；圖卡、圖片、錄音、分類、學習紀錄全部保留，重新啟用就恢復。
   - 備援：如果正式教材完全無法使用（例如詞彙庫讀取失敗），沒有手動設定過的來源會暫時自動使用，避免學生端完全不能練習。
2. **學生端**
   - 所有練習範圍都會排除停用來源，包括系統推薦、複習、自選、錯題集、注音加強、分析推薦，以及家長「直接開始複習」。
   - 「教師自訂教材」分頁只列出已啟用的分類；兩種來源都停用時，會顯示「沒有啟用」並說明在哪裡啟用。
   - 原本只選了停用來源的範圍，會自動改用正式主題並說明一次。原本的選擇會保留，重新啟用後可以選回。
3. **保護正式詞彙、主題、Level**
   - 在詞彙管理刪除正式詞彙會被擋下，並提示改用「停用」。
   - 在分類管理刪除正式主題或 Level 會被略過並說明。教師自訂分類照常可以刪除。
4. **🛠 教材安全修復**（先自動備份，可「復原上次修復」）
   - 會做：重新讀取正式詞彙庫、補回被刪除的正式主題與 Level、清除圖卡上已不存在的分類連結、修正**每位個案**練習範圍中已刪除的分類、重建索引。
   - 不刪除任何資料，也不改教師停用設定。
   - 「復原」只還原教材與範圍，修復後新增的學習紀錄和星星都會保留。
5. **📊 六站實際可用題數**：依三種模式 × 6 站 × 5 星（共 90 格）列出可用詞彙數；不能用的格子會寫出原因。手機寬度下表格可以捲動。
6. **完整性檢查補強**：新增教材來源狀態、個案範圍含已刪除分類的人數、個別詞彙範圍無效的人數、失效分類連結、教師退回待審的圖片數。
7. **修正寫死的版本**：教材版本面板原本寫「程式版本 v20.0」，完整性檢查原本寫「v22.0」，現在都讀同一個版本來源（`APP.build`，目前 v22.3）。唯讀診斷也會顯示來源狀態。

**資料**：只新增一個可缺省欄位 `S.matSrc`（教師按下啟用／停用後才建立），以及修復紀錄 `S.matFix`。沒有格式遷移，學習紀錄不動。

## 3. 已知限制
- 來源設定是整台裝置共用，換裝置要重新設定（與教材本身一樣不會同步）。
- 第3～6站的組合、語句、情境教材不受來源開關影響，這些教材由第06、07批處理。
- 教師分析、詞彙履歷仍會顯示停用來源的歷史紀錄，因為紀錄不刪除。智慧複習是否排除停用來源由第10批處理；家長「直接開始複習」本批已排除。
- 六站可用題數依目前個案設定、「全部教材」範圍計算；第3～6站只顯示「可用／不可用」，不計算題數。

## 4. 您可以自行驗收
1. 教師專區 → 📖 詞彙庫：最上方應有「📚 教材來源管理」，舊版、自訂都顯示「未使用（預設）」。「📚 教材版本」那一行應顯示「程式版本 v22.3」。
2. 首頁 → 聽讀練習 → 第1站，按「自行選擇教材」→「教師自訂教材」：應顯示「沒有啟用」。
3. 回到教材來源管理，按舊版內建教材的「啟用」，再看第2步：會列出水果、交通工具等。按「停用」後恢復原狀。
4. 按「📊 計算六站可用題數」：第1站一星應為 950 個詞彙（依您停用的數量減少）。
5. 按「🛠 教材安全修復」：完成後顯示修復結果；學習紀錄、星星不變。
