# BATCH01-REPORT｜第01批 教材讀取異常修復（v22.1 → v22.2）

> 全部為電腦模擬（Chromium／jsdom）。**沒有您的實際電腦資料，也沒有真機**；您的電腦是否正是以下原因，需用 DIAG-CONSOLE.md 的唯讀診斷確認。

## 1. 已確認的問題原因
依「正式教材載入 → 本機遷移 → 來源整合 → 啟用狀態 → 分類／Level 篩選 → 圖片與注音 → 練習快照 → 各站題庫」逐段追蹤，建立 16 種本機狀態實際重現。**正式教材載入、遷移、來源整合、啟用都正常**（16 種狀態下 1000 詞都在 S.cards、950 有圖）。問題出在後段的三個篩選：

| # | 階段 | 原因 | 重現結果（v22.1） | 會不會只發生在一台裝置 |
|---|---|---|---|---|
| ① **主因** | 分類篩選 | 「自行選擇教材」的範圍以**分類 ID** 存在個案資料（`ext.fl.sel`）。分類被刪除後 ID 沒有清掉；`FL.migDim` 在範圍已存在時直接返回，永遠不會修正 → 聯集為 0 個詞彙。v21.0 第一次進入選擇畫面時，系統會自動把「當時有詞彙的分類」（多為水果、交通工具、民生用品、三餐這 4 個舊分類）存成範圍；之後刪除舊分類，範圍就全部失效。 | 第1、2站「目前教材範圍內沒有符合的詞彙：需要有圖片的圖卡」；選練習數量「全部」也無法開始 | **會**：範圍存在各裝置自己的瀏覽器，手機從未選過或沒刪過分類就正常 |
| ② | 啟用狀態 | 個別學生詞彙範圍（`ext.libSel`）若是空陣列，或是舊版只啟用少數詞時留下的名單，正式詞彙會被全部（或大部分）排除。 | 只剩舊版 18 張；若舊詞彙也刪了＝0 | 會 |
| ③ | 圖片條件 | 正式詞彙的圖片審核預設值（`LIB.defRv`）只在**當次**成功下載 `vocab/default-library.json` 時存在。下載失敗時，本機有設定但沒有審核欄位的詞彙全部沒有圖片 → 不能進入看圖題。 | 正式有圖 950→0；舊詞彙也刪除時全部站別＝0 | 會（看網路／快取） |

其他檢查（皆正常，沒有修改）：本機空白＋初始化標記會重新載入 1000 詞；正式＋自訂並存正確去重；練習快照只在遊戲中有效、不寫入本機；開機流程是先等詞彙庫載入完才顯示畫面。

## 3. 本次實際修改（只有 index.html 的程式，新區段 `/*P24-BEGIN v22.2 … P24-END*/`，放在開機程式之前）
1. **失效範圍自動修正**（`MATFIX.selFix`）：移除已不存在的分類；全部失效時改為目前所有可用的分類（與第一次進入時的預設相同），並在選擇畫面說明一次「原本選擇的 N 個分類已經不存在」。`FL.chk` 與 `FL.migDim` 都會先執行。
2. **教材初始化後重新計算**：系統自動選的範圍（第一次進入或選「全部」）標記 `selAuto`，之後依實際教材重新計算；使用者自己勾選、取消後就不再自動改。`LIB.sync` 後一律 `MAT.bump()`，分類與題庫統計不用舊快取。
3. **個別學生詞彙範圍**（`LIB.selEff`）：只取目前仍存在的正式詞彙；一個都不剩時視為「使用全部正式詞彙」。**原設定保留不刪**；仍有效的範圍照常限制。
4. **審核預設值快取**：成功下載時存到 `S.lib.defRv`；下載失敗時沿用上次成功的版本。教師明確退回待審（`ov.rv='pending'`）不受影響。
5. **訊息更正**：沒有勾選分類→「還沒有選擇教材分類：請勾選分類，或按『全部選取』」；還沒有學會的詞→「還沒有已經學會的詞彙可以複習…」（原本都誤顯示「需要有圖片／注音的詞彙圖卡」）。
6. **唯讀診斷** `MATFIX.diag()`。
7. 程式版本 `build` v22.1→v22.2。

**沒有改的**：教材檔、圖片、錄音、六站題型、教師停用（off）、教師退回待審、學習紀錄、星星、收藏、個案設定。資料遷移：無格式遷移；只會把失效的範圍 ID 改成有效 ID（範圍屬於畫面偏好），並新增 `S.lib.defRv` 快取欄位（可缺省）。

## 6. 您可以自行驗收的方式
**電腦（問題那台）**
1. 先不要更新，開啟網站 → F12 → Console，貼上 DIAG-CONSOLE.md 的指令，把結果存下來（更新前）。
2. 用 GitHub Desktop 更新 index.html（見 PATCH-README.md），Push 後等 1～3 分鐘，`Ctrl`＋`F5`。
3. 再跑一次診斷，「1 版本」應為 v22.2。
4. 首頁→聽讀練習→第1站：若之前是「自行選擇教材」，應看到黃色提示「原本選擇的 N 個分類已經不存在…」，「符合這個難度的可用詞彙」不是 0，按「開始練習」可以作答。
5. 第2站同樣可以開始。練習數量選「全部」也可以開始。
6. 教師專區→紀錄、星星、個案：與更新前相同。
**手機**：重新整理後，第1、2站照常可以練習（不應該變差）。
